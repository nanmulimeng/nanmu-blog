# ADR-0004: 内容精选采用双次独立评分"和判均显"

- 状态:已接受;事实/数学依据见文末2026-10-02勘误,当前契约以spec为准
- 日期:2026-10-02
- 关联:spec §5.2 / §5.5;模式来源 AIHOT

> 2026-10-04有效口径:当前有效公式是均值达门槛,不是两次都达标;三次相对两次调用增加50%。下文“一致高分/更严/33%/预算宽裕”不作现行依据,质量收益和成本在M1实测,见[精选标准](../engine/selection.md)。

## 背景

LLM 单次评分方差大:同一篇内容两次打分可差 20 分以上。选错(漏掉好文/放过水文)直接决定日报栏目成败。

## 决策

- 同一 prompt 对每条内容**独立调用 2 次**(0-100),回执 attemptTag 区分(score-1/score-2)
- 入选判据:`score_1 + score_2 ≥ 2 × threshold`(tier 分级门槛 T1=60 / T2=75)
- 展示分数:`floor((score_1 + score_2) / 2)`——"和判均显"
- 评分记录 append-only(analysis 表),prompt 版本 = 内容哈希,历史可追溯

## 理由

- AIHOT 生产验证的模式:两次独立采样一致给高分才入选,显著抑制偶然高分
- "和 ≥ 2×门槛"等价于"平均达门槛但更严"——一次 100 一次 40(平均 70)在 T2(75)下落选,符合"稳定好文"直觉
- append-only + 版本哈希使换模型/换 prompt 的效果可对比

## 后果(代价)

- 每条目评分调用 ×2(同类管线实测 ~$0.01/天,预算宽裕)

## 被否决的替代方案

1. 单次评分——方差不可控,否决
2. 纯规则预筛(关键词/信源权重)——召回质量差,只能做零成本预筛层(已采用为前置步骤)
3. 三次投票取中位数——成本 +33%,边际收益小,否决

## 2026-10-02数学勘误

决策公式不变;上文理由“均值达标但更严”“两次一致给高分”不成立。和≥2×门槛恰好等价于均值≥门槛,T2=75时100+50会入选。双次评分能否改善质量待本项目样本验证。三次对比两次的调用数增加50%,不是33%。
