# ADR 模板

> 复制本文件为 `NNNN-<短横线标题>.md`(编号接续)。一个 ADR 一个不可逆决策;写完不可改结论,新认知写新 ADR 或改状态为"被取代"。

```markdown
# ADR-NNNN: <决策标题>

- 状态:已接受 | 提议 | 被 ADR-XXXX 取代
- 日期:YYYY-MM-DD
- 关联:spec §X / ADR-YYYY

## 背景
(迫使做决策的约束与事实;引用环境文档而非复述)

## 决策
(做了什么;精确到可执行的程度)

## 理由
(为什么是这个;证据/调研结论要给来源)

## 后果(代价)
(诚实地写代价与新增负担——没有代价的决策不存在)

## 被否决的替代方案
1. 方案 A——否决理由
2. 方案 B——否决理由
```

## 写作要点

- 终态原则:交付文档不引用草稿/评审轮次;被否决方案只留结论与理由
- "后果"必须包含代价——这是防止未来读者盲目崇拜旧决策的部分
- 现有示例:0001-0008(2026-10-02,设计期八项核心决策)
