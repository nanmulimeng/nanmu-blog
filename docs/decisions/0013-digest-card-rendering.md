# ADR-0013: 日报页 aihot 式卡片流——渲染层结构化,产物与引擎零改动

- 状态:已接受(2026-10-26 用户指令「继续按照 aihot 的样式继续进行开发」)
- 日期:2026-10-26
- 关联:[ADR-0012](0012-upstream-aihot-direct.md)(数据源 aihot 直连)/spec 视觉节(「字场·换页碑」token 体系)/[R6 视觉改版](../design/2026-10-07-visual-redesign/)

## 背景

日报页(digest/[id])此前用 Astro `render()` 把引擎 assemble 产出的 markdown 整篇渲染为文章式页面。用户要求呈现样式向 aihot.news(AI 资讯聚合站,本项目数据源与产品形态参照)靠拢:日期分组卡片流、来源/AI 评分徽标、摘要+推荐理由分层。

## 决策

1. **渲染层解析**:`site/src/lib/digest-card.mjs` 把产物 markdown 解析为结构化卡片(板块/标题/来源链接/摘要/理由/来源/展示分),页面按卡片流渲染——**不改引擎 assemble 产物、不重发已发布期**。
2. **信息结构取自 aihot**(板块=左缘时间轴+朱砂节点;卡片=稿纸面+来源胶囊+「AI 评分」胶囊+外链标题+摘要+「理由」楷体段),**视觉语言沿用本站既有 token**(暖纸底/朱砂=热度语义/衬线+楷体+mono)——零换肤,双主题自然继承。
3. 解析器契约以 `node --test` 单测锁定(`site/tests/digest-card.test.mjs`,site 首个测试入口,package.json `npm test`);产物 markdown 的段落形态变化(标题/来源行/一瞥行格式)必须同步解析器与测试。

## 后果与边界

- 产物顶部引言块(模型/成本)在卡片流中不渲染——溯源信息由页面顶部 titleblock 图签(同一 frontmatter 来源)承担,无信息丢失。
- 中英混排空格等文本细节属产物(engine)侧,渲染层不做二次整理。
- markdown 转义(如 `K3\.1`)由解析器反转义,仅处理标点类,不碰语义。
- 首期(2026-10-26)15 卡三板块(83→65 分单调)线上验证通过;RSS/列表页不受影响(消费同一 content collection)。
