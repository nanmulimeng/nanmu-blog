# ADR-0010: ADR-0002「零客户端 JS」的有限例外(提案)

- 状态:提议(未生效——评审通过前,生产站仍按 ADR-0002 现行口径执行)
- 日期:2026-10-09
- 关联:ADR-0002 / [R6 接入方案](../design/2026-10-07-visual-redesign/INTEGRATION-PLAN.md)
- 取代范围:仅 ADR-0002 决策第二条「零客户端 JS:明暗主题纯 CSS `prefers-color-scheme`」;其余条目(Content Layer 契约、git 即 CMS、无后台无数据库、构建不调模型)全部不变
- 当前实施入口:无(提案;实施入口待评审通过后补)

## 背景

R3→R6 视觉与交互评审已认可的全站体验,需要四类客户端行为,与 ADR-0002 的零客户端 JS 条款冲突。同批交付的全站统一原型(`docs/design/2026-10-07-visual-redesign/prototypes/r6/`)已验证这些行为及其降级路径(35/35 矩阵含无 JS、reduced-motion、WebGL 失败用例)。本提案只裁决例外范围与边界,不预设接入时点。

## 决策

允许以下**四类**客户端 JS 例外,每类带硬边界;清单外新增任何客户端脚本(含新的第三方运行时依赖)须先修订本 ADR:

1. **主题三态切换**(全站):一个按钮在 跟随系统/昼/夜 间切换,`localStorage` 持久,`nm-theme` 事件联动 3D 与 poster。
   边界:无 JS 时回退纯 CSS `prefers-color-scheme`(即 ADR-0002 原行为);不改任何内容渲染。
2. **阅读增强**(仅文章详情):阅读进度条、目录 scrollspy 书签、代码块复制、图片 `<dialog>` 展开。
   边界:全部为增强——无 JS 时目录是普通锚链接、代码可手选复制、图片内联显示;不改变正文 DOM 结构。
3. **首页 3D**(仅首页):three r180 **本地自托管固定版**,poster 后动态 import。
   边界:WebGL 探测失败或初始化抛错 → 静态 poster 常驻;reduced-motion → 静态完成态;提供暂停控制与离屏暂停;封面文章标题/摘要存在于 HTML,不依赖 3D 可读。
4. **跨页 View Transitions**(全站,纯 CSS 声明 + 现有挂名管理):`@view-transition{navigation:auto}`。
   边界:旧浏览器自动退化为普通导航(渐进增强);`prefers-reduced-motion` 下 CSS 禁用;声明序(auto 在 reduced 覆盖之前)为受控实现细节。

**共同边界(全部例外适用)**:

- 静态内容独立可读:禁用 JS 后全站内容、导航、RSS 链接完整可用;每批接入验收必须包含无 JS 用例,不达标不合入。
- 页面与构建不调用模型(铁律 6,不变);不引入数据库、管理后台。
- 零第三方运行时:不新增 CDN 脚本、追踪、分析;three 为本地静态文件。
- 体积预算:全站脚本(site.js)gzip ≤ 8KB;首页 3D 相关合计 gzip ≤ 220KB 且不阻塞首绘。超预算须回表裁决,不默放。
- 授权标准:某行为进入生产的理由 = 体验价值 + 降级路径完备,**不是**「原型已经用了」;反之,已认可的体验也不为遵守旧条款而整类删除——逐项按上述边界裁决。

## 理由

- 主题手动切换是长时间阅读站的现实需求,纯 CSS 无法表达用户显式覆盖系统偏好;降级路径恰好等于旧条款行为,冲突面最小。
- 阅读增强四件在 R3–R6 连续多轮评审中被确认为文章页核心体验;它们不触碰内容与数据流,失败模式全部为「回到无增强的可读页面」。
- 首页 3D 是站点主视觉与身份(评审结论);本地自托管保持「git 即 CMS、无外部运行时依赖」的运维心智。
- VT 是浏览器原生渐进增强,无 JS 参与(挂名管理已存在于例外 3 的脚本内)。

## 后果(代价)

- 「零客户端 JS」从物理保证降级为**预算约束 + 验收纪律**:需要持续监督脚本体积与无 JS 矩阵,否则会缓慢回涨。
- 测试矩阵扩大:无 JS、reduced-motion、WebGL 失败三态成为每批验收必测项。
- 自托管 three 与字体分片带来静态资产维护面(升级需手动)。
- 主题按钮引入一处 FOUC 风险点(内联首帧脚本或接受系统色首帧,实施批次裁决)。

## 被否决的替代方案

1. 维持零客户端 JS、删除四类体验——否决:评审已认可的主视觉与阅读体验将整类消失,与「不为遵守旧规则把已认可体验全部删掉」的裁决原则冲突。
2. 无限制放开客户端 JS——否决:失去 ADR-0002 的静态物理保证,漂移方向不可逆。
3. 仅用 CSS 近似(如 `color-scheme` 切换、`:target` 目录)——否决:无法表达三态持久切换;3D 与盖印反馈无 CSS 等价物。
