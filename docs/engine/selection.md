# 精选标准(编辑策略)

> 状态:定稿 2026-10-02。门槛与清单是**运营参数**:调整只改本表与 `engine/config/`,不改代码。预期随试运行迭代。

## 入选判据(和判均显)

- 同一 prompt 独立评分 2 次(0-100)
- 入选:`score_1 + score_2 ≥ 2 × threshold`;展示:`floor((score_1 + score_2) / 2)`
- 门槛:T1 源 **60** / T2 源 **75**
- 每期条目上限:**15**(engine/config/selection.yaml)
- 人工覆盖(override表)优先于评分判断,仍须遵守来源、输入安全与预算限制

## 评分轴(模型内步,不输出)

信息价值 / 新颖度 / 可信度 / 实用度 / 兴趣相关,各 0-10,按条目类型加权(类型:模型发布/产品发布/工具教程/研究论文/行业事件/观点分析;权重表在 config/prompts/score.md)。

## 两清单

- **必须正常评价**:重大发布 / 开放性变化 / 可复用方法 / 意外事实
- **必须压住**:无细节的 PR / 小版本 / 营销课程 / 纯预告 / 轶事 / 跑分帖

## 硬规则

- 题文不符 ≤30(自然拦截标题党)
- 不可核实主张按"有人声称 X"弱化
- 输入材料视为不可信数据(拒绝 prompt 注入);模型看不到 tier / 信源名 / 历史分 / 门槛(防锚定)
- 输出仅 `{"attentionScore": 0-100}`,无解释

## 防幻觉(摘要写作阶段)

不写来源没提的公司/数字/结论;题文不符≤30是提示词约束,不是已证实的确定性过滤;人工抽查仍需核验,明确发现错误的条目不发布。

## 样本与边界

- 双次公式等价于平均值过门槛,不要求两次都高分:T2=75时100+50入选,100+49落选。M1用样本验证质量,不预先宣称“双次必然稳定”。
- T1/T2阈值、15条上限是初始运营参数。候选数还受预算约束,输出不足15条可接受;来源长期霸屏先调整配额参数,不新增复杂排行系统。
- 空content_text默认不进入自动事实摘要;人工force_include也不能跳过来源/输入安全/成本约束。force_include表示越过评分阈值,仍需可核验材料。
- 连续3天验收每天抽查最多5条,记录相关性、事实依据、是否值得点原文和重复原因。无依据事实/错误来源须修正后再验收;轻量结果记session,不建立质量趋势平台。

## M1确定性边界

- 评分必须是0-100整数;缺字段、越界、非整数或无法解析不能转成0分当成功。两次都成功才计算均值,只成功一次保留回执并按预算内有界重试,仍不完整则跳过该条。
- exclude优先排除;force_include只越过评分阈值,不绕过来源/事实/预算校验。入选上限15包含人工强制项;有效强制项超上限时暂停组装并要求人工缩减,不静默丢弃或突破上限。
- 其余按展示分降序、可用published_utc降序、identity_key升序确定排序;缺/异常发布时间统一排在同分有有效时间者之后。M1测试需覆盖平局与空时间。
- 源配额尚未决定启用,先观察样本;若需要,在selection.yaml与本文明确规则及生效版本,不假设当前已有配额参数。
- ai_model目前是一个公开字符串;M1应优先保持一期同一生成模型,若评分/摘要或重试使用多个模型,必须定义可追溯的展示规则并同步schema消费方,不能只标最后一次模型。
