## 探针证据的转入边界(实施先读)

**已由本地探针验证**(机制层,2026-10-20 实测,探针 v2.1 三阶段+selftest 5/5):

- 静态 sandbox:响应头 `CSP: sandbox`(无 allow-scripts)全入口(内嵌/直开)零脚本执行;
- 资源 token 机制:签发绑定会话、30min 到期、跨预览拒绝、预览删除连带失效(410)、重开获新凭证;
- 导航收敛:站内/外链去 href 后实际点击零跳转零请求;页内锚点同文档滚动;
- 服务端拒绝与合法对照:未登录四类资源 401、四路直连写拒绝且数据不变、合法写真实变更。

**尚待实现验证**(探针的临时实现与手工示例**不算**正式服务通过):

- 真实 Astro 构建进预览(探针是手工 HTML 样例);
- 实际 HTML/CSS 改写器(前缀改写+链接去 href+token 注入;探针模板里的改写形态是手工示例,不得当作改写器已通过测试);
- 真实会话与 token 服务(argon2id、服务端会话表、token 记录与清理);
- 文件路径边界(预览目录映射、路径穿越防护在正式实现上的自测);
- 预览清理(24h 过期+总量上限);
- 发布、恢复、部署全链路。

**实施纪律**:优先复用现有构建与发布链路(site 构建、既有 deploy hook 不改);不新增通用权限平台、队列、媒体库或管理仪表盘。

## 批 1 服务骨架、认证会话、编辑与草稿保存

- **目标**:write.nanmu.xyz 最小服务可用:口令登录、会话、编辑器、单记录草稿保存可靠。
- **涉及模块**:workbench 服务(新建);DESIGN §2(架构)、§3(认证)、§4.1(列表)、§4.2(保存)。
- **依赖**:任务 1.0 分面调整;本地开发口令用占位符(真实口令部署属批 4,只进服务器 env)。
- **具体任务**:
  - 1.1 HTTP 服务骨架与路由(/login 页、静态资源、错误兜底);
  - 1.2 口令认证+会话:argon2id、恒定时间比对、服务端会话表、防爆破限速、日志脱敏(§3);
  - 1.3 编辑器+保存 API:单记录一次替换(tmp+fsync+rename 唯一提交点)、rev 乐观锁、draft.prev.json 兜底、60s 周期保存上限(§4.2);
  - 1.4 草稿列表与状态显示(§4.1)。
- **代表性验收**:§4.2 反例表四条(并发 rev 冲突 409/中断恢复得完整旧或新/保存上限/写入不可插入);登录-登出-过期-限速各一轮;日志无口令无正文。
- **失败处理**:保存失败留 prev 兜底,不自动重试写;API 失败不得破坏现有草稿;服务崩溃重启后会话表清理、草稿可恢复。
- **提交边界**:1.0/1.1/1.2/1.3/1.4 各一提交,可独立回退;TDD(RED→GREEN)每任务内执行。
- **停止点**:批 1 全验收+用户复核通过后进批 2;不提前动构建与预览。

## 批 2 真实构建与静态校对预览

- **目标**:预览=真实 Astro 构建产物+静态 sandbox+资源 token+导航收敛,作者能可靠校对。
- **涉及模块**:预览构建(worktree)、改写器(新)、预览路由与 token 服务;DESIGN §4.3 全节。
- **依赖**:批 1 服务骨架与保存。
- **具体任务**:
  - 2.1 预览构建:worktree 构建、产物拷贝独立副本、构建失败留证不建预览;
  - 2.2 **改写器(单测先行)**:根路径前缀改写(HTML href/src/srcset+CSS url())、站内/外部 `<a>` 去 href 留 data-wb-target、页内锚点保留、资源 URL token 注入、CSS 内分片 URL 改写;
  - 2.3 预览服务:HTML 会话鉴权、CSP sandbox 响应头、子资源 token 四项校验(会话/预览 ID/有效期/类别)、字体分片 ACAO、预览删除 410、24h+总量存活清理;
  - 2.4 双预览互不串+哨兵验收(预览含哨兵、公开面零命中)。
- **代表性验收**:探针 v2.1 判据在**真实服务**上全部成立;DESIGN §4.3 十七条反例表;BLOCK 反向(阻断 fonts.css 验收必须 FAIL);改写器单测含动态拼接路径反例(ADR-0010 四入口 JS)。
- **失败处理**:构建失败→operation 失败态;改写遗漏→双预览/哨兵发现即补改写清单;资源加载失败按探针判据转红,不以系统字体静默通过。
- **提交边界**:2.2 改写器单测与实现分开提交;每任务一提交;预览构建与预览服务可独立回退。
- **停止点**:真实预览验收+作者实际校对一篇样稿通过、用户复核后进批 3。

- **目标**:五操作闭环,github/server 双远端一致,中断可恢复。
- **涉及模块**:operations 状态机与落盘、Git 操作;DESIGN §2.1(双远端)、§4.4(发布)、§4.5(撤下)。
- **依赖**:批 2(发布前预览确认);**测试用 bare repo 双远端,不碰生产远端**。
- **具体任务**:
  - 3.1 operations 落盘+七内部态/五界面态;

- **具体任务**:
