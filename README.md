# nanmu-blog

个人博客:手写文章(Astro 5 静态站)+ AI 日报(引擎读 topic-digest 数据自动精选发布)+ RAG 知识库(自用)。

前项目结论:nanmuli-blog(废弃,过度设计教训)、topic-digest(在产,爬取试点)、AIHOT/PowerContext(借鉴对象)——详见 spec §1。
